# A Weather App 0.62.0

This release improves forecast alignment, spacing and readability, adds a compact
saved units dropdown, and fixes geographic map backgrounds disappearing during
forecast refreshes.

- Hourly forecast items share a centered column, with comfortable hover padding
  and no vertical dividers between hours.
- Current conditions use balanced, centered metric blocks, with more room for
  the sunrise and sunset timeline.
- Daily forecasts, detail panels and narrow layouts have improved spacing and
  contrast. Long location names wrap without colliding with the toolbar.
- A compact units dropdown replaces the Auto / Fahrenheit / Celsius buttons.
  Auto shows the resolved unit; manual choices are saved and stay synchronized
  with Settings. Refresh sits immediately to the left of the dropdown.
- Settings dropdowns, the active section indicator and the reserved scrollbar
  gutter make navigation clearer and reduce layout shifts.
- Air quality freshness and offline labels are easier to distinguish, and empty
  forecasts provide clearer guidance.
- Map wind labels are easier to read, and precipitation legends distinguish dry
  hours from small modeled amounts.
- Geographic tiles reload reliably after map-data resets and use the same tile
  geometry as the renderer. Cached backgrounds render after offline reopening;
  missing cached tiles show an unavailable message without making network
  requests. Canceled cached replies no longer read closed devices.

The release pipeline retains Go vulnerability checks, native assessment evidence
and independent reproducibility checks. Native assessment has incomplete
coverage; Qt, GTK and graphics libraries are supplied by the host system.
