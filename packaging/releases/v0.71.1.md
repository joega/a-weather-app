# A Weather App 0.71.1

Fixes automatic updates from 0.70.2 and earlier updater-enabled releases.

Widget translations are embedded in the existing widget file so the release
keeps the runtime inventory accepted by installed updaters. All 0.71.0 language
features remain available. Existing users can choose **Check for updates**, then
**Update and restart**; no manual installation is needed for this recovery.

The release bundle is checked with the verifier shipped in 0.70.2 before
publication.
