# A Weather App 0.61.1

This update fixes map freshness notifications and makes the successful-update
notice smaller and dismissible. It also reduces work when delivering weather
snapshots and reuses bounded provider connections.

- Map tiles reject expanding or unsupported PNG metadata before Qt decodes it.
- Open maps receive stale and expired status changes without requiring new tiles.
- The main screen shows “Updated to 0.61.1.” with a Close button after an update.
- Provider connection reuse and snapshot encoding reduce repeated allocations
  and processing while preserving cancellation and concurrent request handling.
- Release builds retain phase timings, full bounded logs and vulnerability
  assessment evidence, and still require independent byte-identical builds.

The release targets the current tested Omarchy environment. Compatibility with
installations up to 90 days behind is a future validation target, not a promise
for this release. Desktop effects keep their separate Hyprland compatibility
checks.

Native security assessment has incomplete coverage. Qt, GTK and graphics
libraries come from the user's system; release evidence does not scan every
installed library. OpenSSL September 29 advisory applicability/backports and
libjpeg-turbo CVE-2026-75466 applicability remain unresolved and are retained as
warnings. Confirmed affected Arch versions and assessment failures block the
release; unknown coverage is not presented as a clean security result. Go source
and executable vulnerability checks remain mandatory.
