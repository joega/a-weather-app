# A Weather App 0.71.0

This release adds offline language selection across the native app and weather
bar widget.

- Choose English, Spanish, French, German, Portuguese, Japanese, Simplified or
  Traditional Chinese, Ukrainian, Hindi, Italian, Korean, Indonesian or Polish,
  or use **Automatic** to follow system language preferences.
- The app switches languages immediately and remembers your choice. Changing
  language keeps your selected city, forecast, units, viewed hour and open panel.
- Place search and saved-city names can use the selected language. Existing
  weather data remains intact while localized place details refresh.
- App-authored desktop notifications and widget messages are translated. Date
  and number formatting follows regional settings, and forecast times retain
  each city's timezone and daylight-saving changes.

Catalogs are bundled with the app and widget, so interface translations work
offline. Russian system preferences select Ukrainian. Right-to-left languages
are not included in this release.
