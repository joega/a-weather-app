# A Weather App 0.62.1

The forecast window now has gently moving clouds behind its content, and the
wind map uses short, soft blue-gray trails instead of prominent arrows and
speed-label boxes.

- Clear and partly cloudy skies retain restrained cloud cover, with visible
  drift even in calm or north/south winds. Overcast skies retain their
  weather-dependent appearance, and forecast text stays readable.
- The in-app sky works independently of Live desktop activation. Unsupported
  shader renderers receive a static weather-aware background.
- Wind trails follow smoothly interpolated forecast vectors. Point inspection
  shows speed and direction using the saved unit preferences, and map labels
  distinguish sampled forecast resolution from visual interpolation.
- Cloud-only backgrounds update at 20 FPS; rain, snow and enabled lightning
  retain 30 FPS. Cloud motion speed stays consistent when the rate changes.
  The wind map uses a bounded trail budget at about 15 updates per second.
- Animations pause when hidden or minimized, and wind trails pause outside the
  map viewport. Reduced motion provides a useful static presentation. Location
  and forecast-hour changes discard stale trail data.
- Existing offline geographic tile caching and desktop behavior are preserved.

Native rendering was reviewed at desktop and narrow window sizes on the
development laptop. A controlled cloud-only comparison measured approximately
32–33% less GPU graphics-engine time at 20 FPS than at 30 FPS on that machine;
whole-app battery savings and other hardware have not been measured.

The release pipeline retains vulnerability assessments and independent
reproducibility checks. Qt, GTK and graphics libraries are supplied by the host
system; native vulnerability assessment coverage remains incomplete.
