## Go maintenance and reliability

- Manual update checks now report failures when a result cannot be saved.
- Update installation stops before activation if progress status cannot be saved, and retains status-write failures in the reported error.
- Invalid local requests and native test fixtures return explicit JSON errors while preserving validation limits and existing saved-state formats.
- CLI startup, effects processing, and benchmark preparation have clearer lifecycle boundaries, with existing ownership, shutdown, recovery, and heartbeat safeguards retained.
- Go formatting and pinned Staticcheck checks now run locally and in release builds. Network tests use isolated transports, and regression tests cover error boundaries and saved-state isolation.

Existing users on 0.60.0 or newer can use **Update and restart** after this release is published and its repository runtime pin is updated. Saved location, units, notification settings, and bar placement are retained.

Linux x86_64 package for Omarchy. Verify the archive against `SHA256SUMS` and the committed repository pin before extracting. `go-runtime.json` records the source revision and runtime inventory.
