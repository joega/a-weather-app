Compatibility update for Omarchy 4.5, Qt 6.12 and Hyprland 0.56.2.

- Restores the weather update panel's theme colors on Qt 6.12.
- Follows Omarchy's display-language changes without restarting the bar, while
  retaining an explicit language selected in the app.
- Places new weather widgets beside the centered clock. Existing placement is
  preserved.
- Updates the reproducible build target to Omarchy 4.5's native dependencies and
  the signature-verified Go 1.27.4 compiler.
- Adds a streaming limit to advisory-data downloads and requires source and
  packaged widget interaction tests in release builds.
- Verifies a fresh official Go advisory-database fetch even during periods with
  no database changes; known-vulnerable source and binaries still block release.
- Applies the release linker and stack protections to local native-window builds.
