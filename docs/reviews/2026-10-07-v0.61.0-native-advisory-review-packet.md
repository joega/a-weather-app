## Primary-source cross-checks

[Arch AVG-2887](https://security.archlinux.org/AVG-2887) marks curl as not affected. [The upstream CVE-2025-5025 advisory](https://curl.se/docs/CVE-2025-5025.html) limits affected releases to 8.5.0–8.13.0 and fixes the issue in 8.14.0; this inventory has curl 8.22.0-1. That supports treating this CVE as outside the listed upstream affected range. The other CVE in the group still needs its own disposition.

[OpenSSL’s CVE-2022-2068 advisory](https://openssl-library.org/news/secadv/20220621.txt) describes c_rehash command injection in the 1.0.2, 1.1.1 and 3.0 branches and publishes fixed versions. The inventory is OpenSSL 3.6.4-1, while Arch’s row retains an old 1.1.1 affected version and no fixed field. This illustrates why a null tracker fix is a conservative review trigger rather than proof that every newer branch is vulnerable. This is not a comprehensive disposition for OpenSSL’s other candidates.

## Required review outcome

A reviewer must classify the packages as build dependencies and/or user-supplied runtime libraries, resolve candidate advisories using current authoritative sources, record unsupported packages and remaining exposure, and decide whether a short-lived exception to incomplete coverage is justified. A plain “accept the 25 findings” answer would not supply that evidence. The implementation’s [release policy](../../packaging/VULNERABILITY_POLICY.md) defines the inventory/feed-bound acceptance format and seven-day maximum validity.

No file at `packaging/native-advisory-review.json` was created. Broader authoritative coverage or a real reviewed exception is needed before archive creation.

All latest updater/runtime gates now pass in the pinned build. After coverage resolution, validate the accepted native policy and collect before/after timings on the same Ubuntu CI runner class. Local incomplete-run totals are not CI speedup measurements.

declared build-only or safe. Missing libraries, malformed loader output, unknown

collection phase. Failure removes any previous successful summary at the same
